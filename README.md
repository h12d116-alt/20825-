# 🛡️ 세이프바이트 AI (SafeBite AI)
> **규칙 기반 추론 엔진과 음성 안내(TTS)를 활용한 개인 맞춤형 식품 알레르기 경고 웹 애플리케이션**

## 📌 프로젝트 소개
- **핵심 AI (`InferenceEngine`):** 표준 알레르겐 및 파생 원재료 지식 베이스를 기반으로 4단계 규칙(`RULE-01` ~ `RULE-04`)을 적용해 위험도를 추론합니다.
- **보조 AI (`MLClassifierPrototype`):** 식당 직원의 비정형 답변이나 복합 원재료 문장에서 알레르겐·소스·육수·모호성을 추출합니다.
- **접근성 지원:** 시각장애인 및 저시력자를 위한 한국어 음성 안내(TTS)와 3단계 글자 크기 확대 기능을 제공합니다.

## 🌐 웹 배포 방법 (GitHub Pages)
1. 이 저장소의 **Settings** → **Pages** 메뉴로 이동합니다.
2. **Branch**를 `main` (폴더 `/root`)으로 설정하고 **Save**를 누릅니다.
3. 약 1분 뒤 상단에 생성되는 `https://[사용자아이디].github.io/[저장소이름]/` 링크로 접속하면 바로 웹 앱을 사용할 수 있습니다.
